imageCompresser — Browser-based Image Compressor
================================================

1. Open index.html in a recent Chrome, Edge, or Firefox browser.
2. Choose output format, quality, and (optionally) maximum dimension.
3. Drag & drop PNG, JPG, WebP, AVIF, or BMP images, or click Choose your images.
4. Download files individually or use Download all (.zip).

Compression runs locally in the browser. Some already-optimized images won't get smaller.
PNG compression includes optional color-palette reduction; lower quality can change colors.
AVIF support depends on your browser. Animated GIFs are not supported.
Batch ZIP downloads work offline using the bundled JSZip library. See JSZIP-LICENSE.markdown.
Fonts are fetched from Google Fonts; system fonts will be used if offline.

Files: index.html, style.css, script.js, png-optimizer.js, jszip.min.js, favicon.svg, JSZIP-LICENSE.markdown
